Install Aplikasi di HP

Gunakan layar penuh tanpa browser (PWA)

Mode Browser

Aplikasi siap dipasang ke layar utama HP Anda agar bisa dibuka seperti aplikasi native dan tetap berjalan saat offline.

Cara Install di HP Android:

  1. Buka halaman aplikasi ini melalui browser Google Chrome.
  2. Ketuk ikon titik tiga (⋮) di pojok kanan atas browser.
  3. Pilih menu "Install aplikasi" atau "Tambahkan ke Layar Utama".
  4. Ketuk Install — ikon WarungKu akan muncul di menu HP.

Cara Install di iPhone / iPad:

  1. Pastikan membuka tautan ini menggunakan browser Safari.
  2. Ketuk tombol Bagikan (Share) ⍐ di bilah bawah.
  3. Gulir ke bawah dan pilih "Tambah ke Layar Utama" (Add to Home Screen).
  4. Ketuk Tambah (Add) di pojok kanan atas.

Gunakan Supabase Publishable Key

Legacy anon public key segera dinonaktifkan oleh Supabase. Salin Publishable Key (sb_publishable_...) dari menu Project Settings → API Keys di dashboard Supabase Anda.

Wajib diisi

Jalankan SQL berikut di SQL Editor Supabase agar Publishable Key (sb_publishable_...) diizinkan membaca & menyimpan data warung: 

-- 1. Tabel Profil Identitas Warung
CREATE TABLE IF NOT EXISTS public.warung_profiles (
  id TEXT PRIMARY KEY,
  name TEXT NOT NULL,
  tagline TEXT,
  owner TEXT,
  phone TEXT,
  hours TEXT,
  address TEXT,
  footer_note TEXT,
  init_cash BIGINT DEFAULT 0,
  init_qris BIGINT DEFAULT 0,
  init_bank BIGINT DEFAULT 0,
  updated_at TIMESTAMPTZ DEFAULT NOW()
);

-- 2. Tabel Transaksi Kas Warung
CREATE TABLE IF NOT EXISTS public.warung_transactions (
  id TEXT PRIMARY KEY,
  type TEXT NOT NULL,
  amount BIGINT NOT NULL,
  category TEXT NOT NULL,
  note TEXT NOT NULL,
  method TEXT NOT NULL,
  date TEXT NOT NULL,
  created_at TIMESTAMPTZ DEFAULT NOW()
);

-- 3. Aktifkan RLS & Kebijakan Akses Publishable Key
ALTER TABLE public.warung_profiles ENABLE ROW LEVEL SECURITY;
ALTER TABLE public.warung_transactions ENABLE ROW LEVEL SECURITY;

DROP POLICY IF EXISTS "Allow publishable access profiles" ON public.warung_profiles;
CREATE POLICY "Allow publishable access profiles"
  ON public.warung_profiles FOR ALL
  USING (true) WITH CHECK (true);

DROP POLICY IF EXISTS "Allow publishable access transactions" ON public.warung_transactions;
CREATE POLICY "Allow publishable access transactions"
  ON public.warung_transactions FOR ALL
  USING (true) WITH CHECK (true);
